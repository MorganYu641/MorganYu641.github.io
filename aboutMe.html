Personal Coding Project 1: 2D fighting game

I made a 2D fighting game engine featuring:

  • hitbox visualization and accurate hitbox calculation
  • accurate physics and working knockback
  • stun mechanics and frame-based timing
  • keyboard and controller input handling
  • easy extension of characters

The background image shows the sample level on controller in testing mode.

Personal Coding Project 2: Three Body Particle Problem

After being inspired by reading the Three Body Problem novel, I made a 2D physics simulator.

It simulated three particles (celestial bodies) of variable weight, start position, size, color, and starting velocity, then simulated the three of them moving.

The "goal" was to "solve" the Three Body Problem. What I actually did was have fun and mess around.

Personal Coding Project 3: My own CPU

While I'm not finished, I have been designing my own CPU from scratch for the past few months.

I have designed the following logical gates from just the nand gate: NOT, AND, OR, Xor, Mux, DMux, Not16, And16, Or16, Mux16, Or8Way, Mux4Way16, Mux8Way16, DMux4Way16, DMux8Way16

The following mathimatical gates: HalfAdder, FullAdder, Add16, Inc16, ALU

And the following storage gates: Bit, (up to) RAM 16kb, PC
